## BetterInvis
... is a feature-changing magic mod for Minecraft, that **reworks** the **invisibility effect**. The mod is hugely inspired by **Minecraft Dungeons (II)**, in which the effect works pretty similar. An **official Fabric port** & **updates** for the next game drops are **planned**.

### Features
- **Full invisibility**: Stop those items from rendering!
- **Unseeable**: Stop mobs from seeing you! (Distance can be changed in config)
- **Ghost**: Show a ghost of your player model when near! (Distance can be changed in config)
- **Magic Layer**: Show a purple magic layer on top of the ghost when near enough! (Distance can be changed in config. _**Keep it smaller than the ghost distance for a seamless experience!)**_

### How to use
- Easy to use, this mod just overrides the vanilla invisibility effect

### Client & Server Differences
- Singleplayer: **Full functionality**
- Modded Client & Vanilla Server: "Unseeable" **not** available
- Vanilla Client & Modded Server: **Only** "Unseeable" available
- Modded Client & Server: **Full functionality**

### Configuration
Some features can be changed through the mods config file: (singleplayer / server-side)

  - **Ghost:** start & end of fading in blocks
  - **Magic Layer:** start  & end of fading in blocks (keep lower than ghost for a seamless transition!)
  - **Unseeable:** distance. mobs can see players under that value (if a mob sees a player, it's able to follow its scent! -> in other words: this is definitely an intended feature)

### Compatibility
This mod should be compatible with every other mod, but there can be some major problems with performance-mods.

- Tested (fully functional): Sodium, Iris (no shader)
